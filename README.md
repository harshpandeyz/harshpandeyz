## 01 / INTELLIGENT MOB SURVEILLANCE SYSTEM

### **SEE → DETECT → PROTECT → VERIFY**

An AI-powered CCTV system designed to transform a visual incident into **secure, tamper-evident evidence**.

What makes the project interesting is not only the computer vision layer — it is the chain that follows detection.

```text
CAMERA
   │
   ▼
COMPUTER VISION
   │
   ├── Detection
   ├── Event Analysis
   └── Evidence Trigger
            │
            ▼
       SECURITY LAYER
            │
            ├── Encryption
            ├── Hashing
            └── Metadata
            │
            ▼
      BLOCKCHAIN ANCHOR
            │
            ▼
       VERIFICATION
```

**Stack**

`YOLOv8` `OpenCV` `FastAPI` `MongoDB`
`Docker` `Jenkins` `Solidity` `Web3.py`
