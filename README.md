### 🛡️ Intelligent Mob Surveillance System

**See → Detect → Protect → Verify**

An AI-powered CCTV system where a visual event becomes secure, verifiable evidence.

`YOLOv8` `OpenCV` `FastAPI` `MongoDB` `Docker` `Jenkins` `Solidity` `Web3.py`

**The idea:** computer vision detects the event → encryption protects the evidence → hashing checks its integrity → Ethereum anchors the proof → Docker and CI/CD take the system beyond a notebook.
