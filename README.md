### 02 · Featured builds

<img src="assets/project-surveillance.svg" width="100%" alt="Intelligent Mob Surveillance System" />

**Intelligent Mob Surveillance System** — AI video surveillance that detects events of interest in CCTV footage, extracts the relevant clips, encrypts them with AES-256, and anchors SHA-256 hashes on Ethereum so evidence stays tamper-evident. A React dashboard ties detection, review, and verification together.

`Python · YOLOv8 · OpenCV · FastAPI · React · MongoDB · Solidity` — [→ Repository](https://github.com/harshpandeyz/Intelligent-Mob-Surveillance-System)

<img src="assets/project-quantummind.svg" width="100%" alt="QuantumMind AI" />

**QuantumMind AI** — a modular research-intelligence application: Spring Boot backend, React frontend, and Python AI services, composed with Docker Compose over PostgreSQL with JWT auth. Built so each layer can evolve without dragging the others along.

`Spring Boot · React · Python · PostgreSQL · Docker` — [→ Repository](https://github.com/harshpandeyz/QuantumMind)

<img src="assets/project-shopsphere.svg" width="100%" alt="ShopSphere" />

**ShopSphere** — a fully working e-commerce app in React Native and Expo: catalog, search, cart, coupons, checkout, order tracking, reviews, and an admin dashboard, all persisted on-device. Payments and notifications are openly simulated — an honest demo that runs completely offline.

`React Native · Expo · TypeScript` — [→ Repository](https://github.com/harshpandeyz/ShopSphere)

<img src="assets/project-orchestra.svg" width="100%" alt="OrchestraAI" />

**OrchestraAI** — a control plane for AI agents that routes tasks across models, executes tools in an isolated sandbox, and streams cost, memory, and telemetry over SSE. Ships with live provider calls plus an explicitly-labelled deterministic demo mode, so the whole loop is explorable without an API key.

`Node.js · TypeScript · Postgres · Redis` — [→ Repository](https://github.com/harshpandeyz/OrchestraAI)
