## 03 — SELECTED SYSTEMS

### 01 / INTELLIGENT MOB SURVEILLANCE SYSTEM

**AI-powered CCTV → secure evidence → verifiable proof**

A surveillance system designed around a simple question:

> **What happens when a detected event needs to become trustworthy evidence?**

The system combines computer vision, secure storage, cryptography and blockchain verification.

**Architecture**

```text
Camera
  │
  ▼
Computer Vision
  │
  ├── Person Detection
  ├── Crowd Analysis
  └── Event Detection
        │
        ▼
   Evidence Pipeline
        │
        ├── Encryption
        ├── Hashing
        └── Metadata
        │
        ▼
   Blockchain Anchor
        │
        ▼
   Verification Layer
```

**Technology**

`YOLOv8` `OpenCV` `FastAPI` `MongoDB` `Docker`
`Jenkins` `Solidity` `Web3.py`

**Repository**

→ https://github.com/harshpandeyz/intelligent-surveillance-system-v2

### 02 / QUANTUMMIND AI

**Research documents → retrieval → reasoning → response**

QuantumMind AI explores how a research assistant can ground its responses in a private knowledge base instead of relying only on a model's internal knowledge.

The platform combines document ingestion, vector retrieval, conversational context and AI services into one deployable architecture.

**Architecture**

```text
Research Documents
        │
        ▼
   Document Processing
        │
        ▼
   Vector Embeddings
        │
        ▼
      FAISS
        │
        ▼
 Relevant Context
        │
        ▼
    AI Service
        │
        ▼
  Streaming Response
```

**Technology**

`React` `Spring Boot` `FastAPI` `PostgreSQL`
`FAISS` `RAG` `Docker`

**Repository**

→ https://github.com/harshpandeyz/QuantumMind-AI
